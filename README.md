# Portfolio

Modern, responsive portfolio built with **React + Vite + Tailwind CSS**.

## Run locally

```bash
npm install
npm run dev
```

## Update your resume content

Edit:

- `src/data/resume.ts`

Optional:

- Put your resume PDF at `public/resume.pdf` and add a link in `src/data/resume.ts`.

## Build

```bash
npm run build
npm run preview
```
